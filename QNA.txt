
Q: What defines a Binary Search Tree?
A: For every node, all values in the left subtree are smaller, and all values in the right subtree are larger. No duplicates in the standard definition.

Q: What does inorder traversal of a BST produce?
A: A sorted ascending sequence of values.

Q: What are the three classic tree traversals?
A: Preorder: root left right. Inorder: left root right. Postorder: left right root.

Q: What is the time complexity of BST search in the average case?
A: O log n, where n is the number of nodes.

Q: What is the worst case time complexity of BST search?
A: O n, when the tree is skewed and behaves like a linked list.

Q: What is the height of a balanced BST with n nodes?
A: O log n.

Q: Name two self-balancing BSTs.
A: AVL tree and Red-Black tree. Java's TreeMap uses Red-Black.

Q: What is a skewed tree?
A: A tree where every node has only one child, forming a straight line. Height equals n.

Q: What is the difference between a complete and a full binary tree?
A: Complete: all levels filled except possibly the last, filled left to right. Full: every node has 0 or 2 children.

Q: What is the successor of a node in a BST?
A: The smallest node larger than it. Go right once, then left as far as possible.

Q: What is the predecessor of a node in a BST?
A: The largest node smaller than it. Go left once, then right as far as possible.

Q: What is a threaded binary tree?
A: A tree where null child pointers are repurposed to point to inorder predecessor or successor.

Q: What is the minimum and maximum number of nodes in a BST of height h?
A: Minimum h plus 1 in a skewed tree. Maximum 2 to the power h plus 1 minus 1 for a perfect tree.

Q: How do you validate a BST using recursion?
A: Pass down min and max bounds. Each node must be within its parent's bounds. Left child updates max. Right child updates min.

Q: How do you validate a BST using iteration?
A: Simulate inorder traversal with a stack. Keep track of the previous value. Current must always be greater than previous.

Q: Why is the iterative validate BST approach safer for deep trees?
A: It uses an explicit stack on the heap instead of the call stack, avoiding StackOverflowError on skewed trees.

Q: What is the Lowest Common Ancestor in a BST?
A: The node where the two target values diverge. If both values are smaller than current node, go left. If both larger, go right. Otherwise current is the LCA.

Q: Why is LCA easier in a BST than a regular binary tree?
A: Because you can compare values to decide which subtree to search. In a regular binary tree you must search both subtrees.

Q: How do you find the Kth smallest element in a BST?
A: Inorder traversal. Count nodes as you visit them. Stop when count equals k.

Q: What is the space complexity of Kth smallest using iterative inorder?
A: O h for the stack, where h is height.

Q: What is the Morris traversal approach for Kth smallest?
A: Threaded tree technique with O 1 space. Temporarily link predecessor back to current during traversal.

Q: What is the standard binary search template using left less than right?
A: While left less than right, mid equals left plus right minus left divided by 2. If condition met, right equals mid, else left equals mid plus 1. Return left.

Q: Why use left less than right instead of left less than or equal to right in binary search?
A: It guarantees termination and avoids infinite loops. The loop ends with left equals right, which is the answer.

Q: Why calculate mid as left plus right minus left divided by 2?
A: To prevent integer overflow when left and right are large. Direct left plus right divided by 2 can overflow.

Q: What is binary search on answer space?
A: When the input is not sorted but the possible answer range is sorted. Example: minimum eating speed in Koko Eating Bananas.

Q: What is the sliding window technique?
A: Two pointers define a window that expands and contracts to maintain a condition. Used for contiguous subarray or substring problems.

Q: In longest substring without repeating characters, what is the window constraint?
A: All characters inside the window must be unique. Expand right pointer. If duplicate found, shrink left pointer past the previous occurrence.

Q: What data structure tracks characters in the sliding window for substring problems?
A: A HashSet for existence checks, or a HashMap for character to index mapping.

Q: What is the time complexity of sliding window for longest substring?
A: O n. Each character is visited at most twice, once by right pointer and once by left.

Q: How do you solve Number of Islands?
A: DFS or BFS from each unvisited land cell. Mark visited cells as water or use a visited set. Count how many times you start a new search.

Q: Why can you mutate the input grid in Number of Islands?
A: To mark visited cells as water by setting them to zero. This saves O n by m space for a visited matrix.

Q: What is the time and space complexity of Number of Islands using DFS?
A: Time O n times m. Space O n times m in worst case for the recursion stack if the grid is all land.

Q: What is an LRU Cache?
A: Least Recently Used cache with fixed capacity. Evicts the oldest accessed item when full.

Q: What two data structures make up an LRU Cache?
A: A HashMap for O 1 key lookup, and a Doubly Linked List for O 1 move and eviction order.

Q: Why a doubly linked list and not a singly linked list for LRU?
A: You need O 1 removal given a node reference. Singly linked lists require traversal to find the previous node.

Q: What happens on a get operation in LRU Cache if the key exists?
A: Move the node to the front or tail of the linked list to mark it as recently used. Return the value.

Q: What happens on a put operation when the cache is at capacity?
A: Evict the least recently used node from the tail or head of the list. Remove it from the HashMap. Insert the new key-value pair at the front.

Q: What is the time complexity of LRU Cache get and put?
A: O 1 for both operations.

Q: What is the space complexity of an LRU Cache with capacity c?
A: O c.

Q: What Java class implements an LRU Cache for you?
A: LinkedHashMap with accessOrder set to true and overriding removeEldestEntry.

Q: What is the time complexity of HashMap get put and remove?
A: O 1 average case. O n worst case if all keys hash to the same bucket.

Q: What is the time complexity of TreeMap get put and remove?
A: O log n guaranteed, because it is a Red-Black tree.

Q: When do you choose TreeMap over HashMap?
A: When you need sorted order, range queries, or ceiling and floor operations.

Q: What is the time complexity of ArrayList get?
A: O 1.

Q: What is the time complexity of ArrayList add at the end?
A: O 1 amortized. O n when resizing is needed.

Q: What is the time complexity of LinkedList get by index?
A: O n. You must traverse from head or tail.

Q: What is the time complexity of LinkedList add at head or tail?
A: O 1 if you have the head or tail reference.

Q: What data structure backs a PriorityQueue in Java?
A: A binary min-heap.

Q: What is the time complexity of PriorityQueue offer and poll?
A: O log n.

Q: What is the time complexity of peek in a PriorityQueue?
A: O 1.

Q: What are the two common ways to represent a graph?
A: Adjacency matrix and adjacency list.

Q: When is an adjacency matrix better than an adjacency list?
A: When the graph is dense or you need O 1 edge existence checks.

Q: When is an adjacency list better than an adjacency matrix?
A: When the graph is sparse. Space is O V plus E instead of O V squared.

Q: What is the difference between BFS and DFS?
A: BFS uses a queue and explores level by level. DFS uses a stack or recursion and explores as deep as possible first.

Q: When does BFS find the shortest path?
A: In an unweighted graph. The first time you reach a node is via the shortest path.

Q: Why does DFS use less memory than BFS on a wide tree?
A: DFS stack depth is O h. BFS queue can hold an entire level, up to O n over 2 for a complete binary tree.

Q: What is a deque and why is it useful?
A: Double-ended queue. Supports add and remove from both ends in O 1. Used in sliding window maximum problems.

Q: What is a Trie?
A: A prefix tree for efficient string storage and retrieval. Each node represents a character. Path from root to node forms a prefix.

Q: What is the time complexity to insert or search a string of length m in a Trie?
A: O m.

Q: What is topological sort?
A: Ordering of nodes in a directed acyclic graph such that for every edge u to v, u comes before v.

Q: What algorithm finds topological sort?
A: Kahn's algorithm using BFS and in-degree counting, or DFS with a post-order stack.

Q: What is a Union-Find data structure?
A: Disjoint set for tracking connected components. Supports find and union in nearly O 1 with path compression.

Q: What is amortized time complexity?
A: Average time per operation over a sequence. Example: ArrayList add is O 1 amortized even though occasional resizes are O n.

Q: What is tail recursion?
A: A recursive call that is the last operation in the function. Theoretically optimizable to iteration, but Java does not guarantee this optimization.

Q: Why might iteration be preferred over recursion in production code?
A: No risk of stack overflow, better performance due to no function call overhead, and easier to reason about state.

Q: When is recursion clearly better for trees?
A: When the problem is naturally divided into identical subproblems on subtrees, and code clarity matters more than micro-optimization.

Q: What is memoization?
A: Caching results of expensive function calls to avoid redundant computation. Top-down dynamic programming.

Q: What is tabulation?
A: Bottom-up dynamic programming. Fills a table iteratively without recursion.

Q: What is the difference between a stack and a queue?
A: Stack is LIFO last in first out. Queue is FIFO first in first out.

Q: What is a min-heap vs a max-heap?
A: Min-heap: parent is smaller than children. Max-heap: parent is larger than children.

Q: How do you build a heap from an unsorted array?
A: Heapify. Start from the last non-leaf node and sift down. Time O n.

Q: What is a self-balancing binary search tree?
A: A BST that automatically keeps its height small after insertions and deletions. Examples: AVL, Red-Black.

Q: What is the balance factor in an AVL tree?
A: Height of left subtree minus height of right subtree. Must be minus 1, 0, or 1.

Q: What is a Red-Black tree?
A: A self-balancing BST where each node is red or black. Root is black. No two reds in a row. Every path from a node to null has the same number of black nodes.

Q: What is the load factor in a HashMap?
A: The ratio of entries to buckets. When it exceeds a threshold, usually 0.75, the HashMap resizes.

Q: What happens when a HashMap resizes?
A: It creates a new larger array and rehashes all existing entries into the new buckets. This is the O n operation behind amortized O 1.

Q: What is the difference between a HashSet and a TreeSet?
A: HashSet uses a HashMap for O 1 operations with no ordering. TreeSet uses a TreeMap for O log n operations with sorted ordering.

Q: What is a sentinel node in linked lists?
A: A dummy node placed at the head or tail to simplify edge cases like empty lists or head removal.

Q: What is backtracking?
A: A form of DFS that explores all possible choices, and undoes the last choice when a dead end is reached. Example: N-Queens.

Q: What is the difference between a complete tree and a perfect tree?
A: Perfect: all internal nodes have two children and all leaves are at the same level. Complete: all levels filled except possibly the last, filled left to right.

Q: What is the diameter of a binary tree?
A: The longest path between any two nodes. It may or may not pass through the root.

Q: What is path sum in a binary tree?
A: The sum of node values along a path, typically root to leaf.

Q: What are the three cases for deleting a node in a BST?
A: Leaf node: simply remove. One child: replace with the child. Two children: replace with inorder successor or predecessor, then delete that successor or predecessor.

Q: What is a range query in a BST?
A: Finding all elements between a low and high value. You prune branches: if node value is less than low, only search right. If greater than high, only search left.

Q: What is a segment tree?
A: A tree for range queries and updates on an array. Each node stores an aggregate of a segment. Build O n. Query and update O log n.

Q: What is a Fenwick tree or Binary Indexed Tree?
A: A data structure for prefix sums and range queries with O log n update and query, using less space than a segment tree.

Q: What is the difference between a graph and a tree?
A: A tree is a connected acyclic graph. Graphs can have cycles and disconnected components.

Q: What is a directed acyclic graph?
A: A directed graph with no cycles. Required for topological sorting.

Q: What is in-degree and out-degree in a directed graph?
A: In-degree: number of edges entering a node. Out-degree: number of edges leaving a node.

Q: What is a bipartite graph?
A: A graph whose nodes can be divided into two sets such that no edge connects nodes within the same set. Checkable with BFS coloring.

Q: What is Dijkstra's algorithm used for?
A: Shortest path from a source to all nodes in a weighted graph with non-negative edges.

Q: What is the time complexity of Dijkstra with a priority queue?
A: O E log V.

Q: Why does Dijkstra fail with negative edge weights?
A: Because once a node is popped from the priority queue, its shortest distance is assumed final. Negative weights later could invalidate this.

Q: What algorithm handles negative weights?
A: Bellman-Ford. Time O V times E.

Q: What is dynamic programming?
A: Solving complex problems by breaking them into overlapping subproblems, solving each once, and storing the result.

Q: What are the two properties a problem needs for dynamic programming?
A: Optimal substructure and overlapping subproblems.

Q: What is the knapsack problem?
A: Given items with weights and values, maximize total value without exceeding weight capacity. Classic 0-1 DP.

Q: What is the longest common subsequence problem?
A: Find the longest sequence present in both strings in the same relative order but not necessarily contiguous.

Q: What is the edit distance problem?
A: Minimum number of insertions, deletions, and substitutions to transform one string into another.

Q: What is a greedy algorithm?
A: Makes the locally optimal choice at each step with the hope of finding a global optimum. Does not always yield the optimal solution.

Q: When does a greedy algorithm work?
A: When the problem has the greedy choice property and optimal substructure. Example: interval scheduling, minimum spanning tree.

Q: What is Kruskal's algorithm?
A: A greedy algorithm to find the minimum spanning tree by sorting edges by weight and adding them if they do not form a cycle. Uses Union-Find.

Q: What is Prim's algorithm?
A: A greedy algorithm to find the minimum spanning tree by growing the tree from an arbitrary start node, adding the cheapest edge connected to the tree.

Q: What is a spanning tree?
A: A subgraph that includes all vertices and is a tree, meaning it is connected and acyclic.

Q: What is the handshake lemma in graph theory?
A: The sum of all vertex degrees equals twice the number of edges.

Q: What is Euler's formula for planar graphs?
A: V minus E plus F equals 2, where V is vertices, E is edges, F is faces.

Q: What is a clique in a graph?
A: A subset of vertices where every two distinct vertices are adjacent.

Q: What is an independent set in a graph?
A: A set of vertices with no edges connecting any two of them.

Q: What is memoization space complexity typically?
A: O n for the memo table, plus O n for the recursion stack if using top-down.

Q: What is the space complexity of bottom-up tabulation?
A: Often O n for the DP array, but can sometimes be optimized to O 1 if only the previous state is needed.

Q: What is the two-pointer technique?
A: Using two indices, often starting at opposite ends or both at the start, to traverse a structure with O n time and O 1 space.

Q: What is the fast and slow pointer technique?
A: Two pointers moving at different speeds. Used to detect cycles in linked lists or find the middle element.

Q: What is Floyd's cycle detection algorithm?
A: Tortoise and hare. Move slow pointer by one and fast pointer by two. If they meet, a cycle exists.

Q: What is a bit manipulation trick to check if a number is a power of two?
A: n greater than 0 and n bitwise and n minus 1 equals 0.

Q: What is the XOR of a number with itself?
A: 0.

Q: What is the XOR of a number with zero?
A: The number itself.

Q: What is the time complexity of merge sort?
A: O n log n in all cases.

Q: What is the space complexity of merge sort?
A: O n for the auxiliary array.

Q: What is the time complexity of quicksort in average and worst case?
A: Average O n log n. Worst O n squared when the pivot is always the smallest or largest element.

Q: How do you avoid worst case in quicksort?
A: Randomized pivot selection, or median-of-three.

Q: What is heap sort time and space complexity?
A: Time O n log n. Space O 1 auxiliary.

Q: What is counting sort?
A: Non-comparison sort for integers with a known range. Time O n plus k where k is the range. Space O k.

Q: What is radix sort?
A: Sorts numbers digit by digit, using counting sort as a subroutine. Time O d times n plus k where d is digits.

Q: What is stable sorting?
A: A sort that preserves the relative order of equal elements. Merge sort and counting sort are stable. Quick sort is not stable by default.

Q: What is the difference between a process and a thread?
A: A process has its own memory space. Threads share the same memory space within a process. Context switching between threads is cheaper.

Q: What is a race condition?
A: When the outcome depends on the relative timing of events, such as two threads accessing shared data without synchronization.

Q: What is a deadlock?
A: When two or more threads are blocked forever, each waiting for a resource held by another.

Q: What are the four Coffman conditions for deadlock?
A: Mutual exclusion, hold and wait, no preemption, circular wait.

Q: What is a semaphore?
A: A synchronization primitive that controls access to a resource through permits. A mutex is a binary semaphore.

Q: What is the difference between a mutex and a semaphore?
A: A mutex allows only one thread to access a resource and must be released by the same thread. A semaphore can allow multiple threads and can be released by any thread.

Q: What is a deadlock prevention strategy?
A: Lock ordering: always acquire locks in a consistent global order to prevent circular wait.

Q: What is the difference between TCP and UDP?
A: TCP is connection-oriented, reliable, ordered delivery with congestion control. UDP is connectionless, unreliable, faster, no ordering guarantee.

Q: What is the three-way handshake in TCP?
A: SYN, SYN-ACK, ACK. Establishes a connection.

Q: What is the time to live field in an IP packet?
A: A counter that decrements at each hop. Prevents packets from circulating forever in routing loops.

Q: What is a load balancer?
A: Distributes incoming traffic across multiple servers to improve availability and scalability.

Q: What are common load balancing algorithms?
A: Round robin, least connections, IP hash, weighted round robin.

Q: What is consistent hashing?
A: A hashing technique that minimizes reorganization when the number of slots changes. Used in distributed caches like Memcached and DynamoDB.

Q: What is a reverse proxy?
A: A server that sits in front of web servers and forwards client requests to them. Examples: Nginx, HAProxy.

Q: What is database indexing?
A: A data structure, usually a B-Tree, that improves the speed of data retrieval at the cost of slower writes and more storage.

Q: What is the difference between a primary key and a unique key?
A: Primary key cannot be null and uniquely identifies a row. Unique key can have one null and enforces uniqueness.

Q: What is database normalization?
A: Organizing data to reduce redundancy and improve integrity. First normal form eliminates repeating groups. Third normal form eliminates transitive dependencies.

Q: What is an ACID transaction?
A: Atomicity, Consistency, Isolation, Durability. Guarantees reliable processing of database transactions.

Q: What is the CAP theorem?
A: In a distributed data store, you can only guarantee two of three: Consistency, Availability, Partition tolerance.

Q: What is eventual consistency?
A: A consistency model where updates propagate asynchronously. All replicas will eventually converge to the same value.

Q: What is a distributed transaction?
A: A transaction that spans multiple databases or services. Often handled with two-phase commit or sagas.

Q: What is the difference between a monolith and microservices?
A: Monolith is a single deployable unit. Microservices are independently deployable services that communicate over a network.

Q: What is an API gateway?
A: A single entry point for clients that routes requests to microservices, handles authentication, rate limiting, and response aggregation.

Q: What is circuit breaker pattern?
A: Prevents cascading failures in distributed systems. If a service fails repeatedly, the breaker opens and requests fail fast instead of waiting.

Q: What is idempotency?
A: An operation that produces the same result whether executed once or multiple times. Critical for retries in distributed systems.

Q: What is a saga pattern?
A: A sequence of local transactions where each service updates its data and publishes an event to trigger the next step. Compensating transactions handle failures.

Q: What is the difference between REST and gRPC?
A: REST uses HTTP and JSON, human-readable, stateless. gRPC uses HTTP2 and Protocol Buffers, binary, faster, supports streaming and strong typing.

Q: What is GraphQL?
A: A query language for APIs that allows clients to request exactly the fields they need, reducing over-fetching and under-fetching.

Q: What is the N plus 1 query problem?
A: Executing one query for the main data and then N additional queries for related data. Solved with joins or data loader batching.

Q: What is caching and what are common eviction policies?
A: Storing copies of data for fast access. Policies: LRU least recently used, LFU least frequently used, FIFO first in first out, TTL time to live.

Q: What is a cache stampede?
A: When a cached item expires and multiple requests simultaneously hit the database to regenerate it. Solved with locks, probabilistic early expiration, or single-flight pattern.

Q: What is a content delivery network?
A: A geographically distributed network of proxy servers that cache content closer to users to reduce latency.

Q: What is horizontal vs vertical scaling?
A: Horizontal: adding more machines. Vertical: adding more power to an existing machine. Horizontal is preferred for distributed systems.

Q: What is sharding?
A: Splitting a database into smaller pieces called shards, distributed across multiple servers, often by a shard key.

Q: What is a hot shard?
A: A shard that receives disproportionately more traffic than others, becoming a bottleneck.

Q: What is MapReduce?
A: A programming model for processing large datasets in parallel. Map phase filters and sorts. Reduce phase summarizes.

Q: What is the difference between strong consistency and sequential consistency?
A: Strong: all reads see the latest write. Sequential: all operations appear to execute in some sequential order consistent with each program's order.

Q: What is a vector clock?
A: A mechanism for determining the partial ordering of events in a distributed system and detecting causality violations.

Q: What is the difference between authentication and authorization?
A: Authentication verifies who you are. Authorization determines what you are allowed to do.

Q: What is OAuth 2?
A: An authorization framework that enables third-party applications to obtain limited access to a user's resources without exposing credentials.

Q: What is a JWT?
A: JSON Web Token. A compact, self-contained way to transmit information between parties as a JSON object, signed for verification.

Q: What is the difference between symmetric and asymmetric encryption?
A: Symmetric uses one key for both encryption and decryption. Asymmetric uses a public key to encrypt and a private key to decrypt.

Q: What is HTTPS?
A: HTTP over TLS. Encrypts the communication between client and server using asymmetric encryption for the handshake and symmetric for the data transfer.

Q: What is a SQL injection attack?
A: Injecting malicious SQL code through user input. Prevented with parameterized queries and ORM frameworks.

Q: What is XSS cross-site scripting?
A: Injecting malicious scripts into web pages viewed by other users. Prevented by sanitizing user input and using content security policies.

Q: What is CSRF cross-site request forgery?
A: Tricking a user's browser into performing unwanted actions on a trusted site where they are authenticated. Prevented with CSRF tokens.

Q: What is rate limiting?
A: Controlling the number of requests a client can make in a given time period to prevent abuse and ensure fair usage.

Q: What is a bloom filter?
A: A space-efficient probabilistic data structure used to test whether an element is a member of a set. False positives are possible, false negatives are not.

Q: What is a skip list?
A: A probabilistic data structure that allows fast search within an ordered sequence. Average O log n for search, insert, delete.

Q: What is a hyperloglog?
A: A probabilistic algorithm for counting distinct elements in a multiset using very little memory.

Q: What is the difference between a deep copy and a shallow copy?
A: Shallow copy duplicates the object but references the same nested objects. Deep copy duplicates everything recursively.

Q: What is immutability and why is it useful?
A: An object whose state cannot change after creation. Useful for thread safety, simpler reasoning, and preventing accidental modifications.

Q: What is a memory leak?
A: When memory that is no longer needed is not released, causing the application to consume increasing amounts of memory over time.

Q: What is garbage collection?
A: Automatic memory management that reclaims memory occupied by objects no longer in use. Java uses generational garbage collection.

Q: What are the generations in Java's garbage collector?
A: Young generation for new objects, old generation for long-lived objects, and permanent or metaspace for class metadata.

Q: What is the difference between a strong reference and a weak reference in Java?
A: Strong references prevent garbage collection. Weak references allow the object to be garbage collected when no strong references exist.

Q: What is reflection in Java?
A: The ability to inspect and modify classes, methods, and fields at runtime. Powerful but slow and breaks encapsulation.

Q: What is the difference between compile-time and runtime polymorphism?
A: Compile-time: method overloading. Runtime: method overriding.

Q: What is the difference between an abstract class and an interface in Java?
A: Abstract class can have state and constructors. Interface originally could not, but since Java 8 can have default and static methods.

Q: What is the difference between final, finally, and finalize?
A: Final: immutable variable or non-overridable method. Finally: block executed after try-catch. Finalize: method called by garbage collector before destruction, deprecated.

Q: What is the difference between equals and hashCode?
A: Equals checks logical equality. HashCode returns an integer for hashing. If two objects are equal, they must have the same hashCode.

Q: What is the contract of compareTo?
A: Returns negative if this object is less, zero if equal, positive if greater. Must be consistent with equals for sorted collections.

Q: What is a deadlock in Java?
A: When two or more threads are blocked forever, waiting for each other to release locks.

Q: What is the volatile keyword in Java?
A: Guarantees visibility of changes to variables across threads. Does not guarantee atomicity for compound operations.

Q: What is the synchronized keyword in Java?
A: Ensures that only one thread can execute a block of code or method on an object at a time.

Q: What is a ReentrantLock?
A: A mutual exclusion lock with the same basic behavior as synchronized but with extended capabilities like timed lock waits and fairness policies.

Q: What is a CountDownLatch?
A: A synchronization aid that allows one or more threads to wait until a set of operations being performed in other threads completes.

Q: What is a CyclicBarrier?
A: A synchronization aid that allows a set of threads to all wait for each other to reach a common barrier point.

Q: What is CompletableFuture in Java?
A: A class for asynchronous programming that supports chaining operations, combining futures, and handling exceptions without blocking.

Q: What is the difference between Callable and Runnable?
A: Callable returns a result and can throw a checked exception. Runnable does neither.

Q: What is a thread pool and why use one?
A: A managed collection of worker threads that reuse threads to execute tasks, reducing the overhead of thread creation.

Q: What is the difference between submit and execute on an ExecutorService?
A: Submit returns a Future. Execute returns void and is used for Runnable tasks.

Q: What is the ForkJoinPool?
A: A thread pool for divide-and-conquer algorithms. Uses work-stealing to balance load between threads.

Q: What is a stream in Java?
A: A sequence of elements supporting sequential and parallel aggregate operations like map, filter, and reduce.

Q: What is the difference between intermediate and terminal operations in streams?
A: Intermediate operations return a new stream and are lazy. Terminal operations produce a result or side effect and trigger processing.

Q: What is lazy evaluation in streams?
A: Operations are not executed until a terminal operation is invoked, allowing optimization like short-circuiting.

Q: What is a lambda expression in Java?
A: An anonymous function that can be passed around as a parameter. Provides a clear and concise way to represent one method interface.

Q: What is a functional interface?
A: An interface with exactly one abstract method. Examples: Runnable, Callable, Comparator, Predicate.

Q: What is the difference between map and flatMap in streams?
A: Map transforms each element into another element. FlatMap transforms each element into a stream and flattens the result into a single stream.

Q: What is optional in Java?
A: A container object that may or may not contain a non-null value. Helps avoid null pointer exceptions.

Q: What is the builder pattern?
A: A creational pattern that separates the construction of a complex object from its representation, allowing step-by-step construction.

Q: What is the singleton pattern and what are its pitfalls?
A: Ensures only one instance exists. Pitfalls: testing difficulty, hidden dependencies, thread safety issues without proper synchronization.

Q: What is dependency injection?
A: A design pattern where objects receive their dependencies from external sources rather than creating them internally. Promotes loose coupling.

Q: What is inversion of control?
A: A principle where the control of object creation and lifecycle is transferred to a container or framework, like Spring.

Q: What is aspect-oriented programming?
A: A programming paradigm that aims to increase modularity by allowing the separation of cross-cutting concerns like logging and transactions.

Q: What is an ORM?
A: Object-Relational Mapping. A technique that lets you query and manipulate data from a database using an object-oriented paradigm.

Q: What is the difference between optimistic and pessimistic locking?
A: Optimistic: no lock during read, check for conflicts before write. Pessimistic: lock the resource during the entire transaction.

Q: What is database denormalization?
A: Introducing redundancy into a database to improve read performance at the cost of write performance and storage.

Q: What is an inverted index?
A: A data structure that maps content like words to their locations in a document or set of documents. Core to search engines.

Q: What is the difference between a relational and a NoSQL database?
A: Relational uses tables with schemas and SQL. NoSQL uses flexible schemas like key-value, document, column-family, or graph stores.

Q: What is eventual consistency in NoSQL?
A: A model where updates to a database will propagate to all replicas over time, but reads may temporarily return stale data.

Q: What is a materialized view?
A: A database object that contains the results of a query, physically stored and refreshed periodically for fast reads.

Q: What is an execution plan in SQL?
A: A visual or textual representation of how the database engine will execute a query, showing index usage and join strategies.

Q: What is the difference between a clustered and non-clustered index?
A: Clustered determines the physical order of data. Non-clustered is a separate structure with pointers to the data.

Q: What is a covering index?
A: An index that includes all columns needed for a query, so the database does not need to look up the actual table.

Q: What is the difference between a left join and an inner join?
A: Inner join returns only matching rows. Left join returns all rows from the left table and matching rows from the right, nulls for non-matches.

Q: What is a window function in SQL?
A: A function that performs calculations across a set of table rows related to the current row, like row number or rank.

Q: What is the difference between where and having in SQL?
A: Where filters rows before grouping. Having filters groups after aggregation.

Q: What is a stored procedure?
A: A precompiled collection of SQL statements stored in the database, callable by name.

Q: What is connection pooling?
A: Caching database connections so they can be reused, avoiding the overhead of establishing a new connection per request.

Q: What is the saga pattern in distributed transactions?
A: A sequence of local transactions where each step publishes an event to trigger the next. Compensating transactions undo work on failure.

Q: What is an event-driven architecture?
A: A design where services communicate by producing and consuming events, typically through a message broker like Kafka.

Q: What is Apache Kafka?
A: A distributed event streaming platform used for building real-time data pipelines and streaming applications.

Q: What is a Kafka topic?
A: A category or feed name to which records are published. Topics are partitioned and replicated for scalability.

Q: What is the difference between Kafka and RabbitMQ?
A: Kafka is a log-based streaming platform with high throughput and persistence. RabbitMQ is a traditional message broker with complex routing.

Q: What is Kubernetes?

Q: What is a Docker container?

Q: What is CI/CD?

Q: What is canary deployment?

Q: What is infrastructure as code?

Q: What is observability?
A: The ability to understand the internal state of a system by examining its outputs: logs, metrics, and traces.

Q: What is the difference between logging, metrics, and tracing?
A: Logging: discrete events. Metrics: numeric data over time. Tracing: following a request across multiple services.

Q: What is OpenTelemetry?
A: An open-source observability framework for collecting traces, metrics, and logs from applications.

Q: What is a runbook?
A: A documented set of procedures for responding to alerts and incidents in production.

Q: What is an SLO?

Q: What is an SLA?

Q: What is an error budget?
A: The acceptable amount of unreliability derived from the SLO. When exhausted, new feature work stops in favor of reliability.

Q: What is a post-mortem?
A: A blameless analysis of an incident to identify root causes and prevent recurrence.

Q: What is the difference between latency and throughput?
A: Latency is the time to process a single request. Throughput is the number of requests processed per unit time.

Q: What is tail latency?
A: The latency experienced by the slowest requests, like the 99th percentile, often more important than average latency.

Q: What is backpressure?
A: A mechanism where a downstream system signals an upstream system to slow down when it is overwhelmed.

Q: What is a circuit breaker?
A: A pattern that stops calling a failing service after a threshold, returning a fallback instead to prevent cascading failures.

Q: What is bulkheading?
A: Isolating failures by partitioning resources so that a failure in one partition does not exhaust resources for others.

Q: What is timeout vs deadline?
A: Timeout: how long to wait for a single operation. Deadline: the absolute time by which an entire request must complete.

Q: What is idempotency in HTTP methods?

Q: What is the difference between PUT and PATCH?

Q: What is a RESTful API?

Q: What is HATEOAS?

Q: What is gRPC?

Q: What is Protocol Buffers?
A: A language-neutral, platform-neutral mechanism for serializing structured data, smaller and faster than JSON.

Q: What is GraphQL's N plus 1 problem?

Q: What is the difference between authentication and authorization?

Q: What is a man-in-the-middle attack?

Q: What is public key infrastructure?

Q: What is the difference between unit tests and integration tests?
A: Unit tests isolate a single component with mocks. Integration tests verify that multiple components work together.

Q: What is test-driven development?

Q: What is mocking in unit testing?

Q: What is code coverage?

Q: What is the difference between black box and white box testing?

Q: What is A-B testing?

Q: What is feature flagging?

Q: What is technical debt?

Q: What is refactoring?

Q: What is the single responsibility principle?

Q: What is the open-closed principle?

Q: What is the interface segregation principle?

Q: What is the dependency inversion principle?

Q: What is clean code?
A: Code that is easy to understand, easy to change, well-tested, and free of duplication.

Q: What is the difference between cohesion and coupling?
A: Cohesion measures how related the responsibilities within a module are. Coupling measures dependency between modules. High cohesion and low coupling are goals.

Q: What is an architectural decision record?
A: A document that captures an important architectural decision made along with its context and consequences.

Q: What is domain-driven design?

Q: What is a bounded context?

Q: What is CQRS?

Q: What is event sourcing?

Q: What is the strangler fig pattern?

Q: What is a data mesh?
A: An architectural paradigm that treats data as a product, with decentralized ownership by domain teams.

Q: What is the CAP theorem in practice?
A: During a network partition, you must choose between consistency and availability. Most systems choose availability with eventual consistency.

Q: What is a vector database?
A: A database optimized for storing and querying high-dimensional vectors, used in similarity search and embeddings.

Q: What is an embedding in machine learning?
A: A numerical representation of data like text or images in a high-dimensional space where similar items are closer together.

Q: What is a recommendation system?
A: A system that predicts user preferences to suggest items, using collaborative filtering, content-based filtering, or hybrid approaches.

Q: What is collaborative filtering?
A: Making recommendations based on the behavior and preferences of similar users.

Q: What is content-based filtering?
A: Making recommendations based on the attributes of items a user has liked in the past.

Q: What is the cold start problem?
A: The challenge of making recommendations for new users or new items with no historical interaction data.

Q: What is pairwise loss in ranking models?
A: A loss function that optimizes the relative ordering of item pairs rather than absolute relevance scores, often used in learning to rank.

Q: What is a knowledge graph?
A: A network of real-world entities and their relationships, used to enhance search and recommendations with structured semantics.

Q: What is the difference between a monorepo and polyrepo?
A: Monorepo stores all code in one repository. Polyrepo splits code into multiple repositories, often per service.

Q: What is trunk-based development?
A: A branching model where developers merge small, frequent changes directly to the main branch, minimizing long-lived branches.

Q: What is Git rebase vs merge?
A: Rebase rewrites history to create a linear commit sequence. Merge preserves history with a merge commit. Rebase is cleaner for private branches.

Q: What is a commit hash in Git?

Q: What is a Git hook?
A: A script that Git executes before or after events like commits, pushes, or merges, used for validation and automation.

Q: What is semantic versioning?

Q: What is a package manager?
A: A tool that automates the process of installing, upgrading, configuring, and removing software dependencies.

Q: What is the difference between a library and a framework?
A: A library is code you call. A framework calls your code, inverting control.

Q: What is dependency hell?

Q: What is vendoring?

Q: What is a service mesh?

Q: What is a sidecar pattern?

Q: What is serverless computing?

Q: What is edge computing?

Q: What is a webhook?
A: An HTTP callback triggered by an event, allowing real-time notifications between systems.

Q: What is polling vs pushing?

Q: What is WebSocket?

Q: What is the difference between TCP and HTTP?
A: TCP is a transport layer protocol for reliable data transfer. HTTP is an application layer protocol built on top of TCP for web communication.

Q: What is a reverse proxy vs a forward proxy?

Q: What is a firewall?

Q: What is a VPN?

Q: What is DNS and how does it work?

Q: What is a CDN edge server?

Q: What is the difference between horizontal and vertical partitioning in databases?

Q: What is an ORM N plus 1 query and how do you fix it?

Q: What is database connection leaking?

Q: What is a prepared statement?
A: A precompiled SQL statement with placeholders for parameters, improving performance and preventing SQL injection.

Q: What is optimistic locking with a version number?

Q: What is a composite index?
A: An index on multiple columns. Column order matters; queries must use the leading columns to benefit.

Q: What is index selectivity?
A: The ratio of distinct values to total rows. High selectivity means the index is more effective at filtering rows.

Q: What is a full table scan?
A: When the database reads every row in a table to satisfy a query, usually because no suitable index exists.

Q: What is the difference between truncate and delete in SQL?
A: Delete removes rows one by one and can be rolled back. Truncate is faster, deallocates pages, and cannot be rolled back in most databases.

Q: What is a savepoint in a transaction?
A: A point within a transaction to which you can roll back without undoing the entire transaction.

Q: What is two-phase commit?
A: A distributed transaction protocol where all participants vote to commit in phase one, then actually commit in phase two.

Q: What is the difference between a message queue and a pub-sub system?

Q: What is Apache ZooKeeper?
A: A centralized service for maintaining configuration, naming, and providing distributed synchronization.

Q: What is the Raft consensus algorithm?

Q: What is etcd?

Q: What is a liveness probe in Kubernetes?

Q: What is Helm?

Q: What is a Kubernetes ConfigMap?

Q: What is a Kubernetes Secret?

Q: What is a persistent volume in Kubernetes?

Q: What is the difference between a stateful and stateless service?

Q: What is session affinity or sticky sessions?

Q: What is a distributed cache?

Q: What is cache invalidation?

Q: What is write-through caching?

Q: What is write-back caching?
A: Data is written to the cache first and asynchronously written to the backing store later. Faster but riskier.

Q: What is a cache aside or lazy loading pattern?

Q: What is read-through caching?

Q: What is a thundering herd?

Q: What is request coalescing?
A: Combining multiple identical requests into one backend request, reducing load.

Q: What is a poison pill message?

Q: What is a dead letter queue?
A: A queue for messages that could not be processed successfully after retries, allowing inspection without blocking the main queue.

Q: What is idempotency key?
A: A unique identifier sent with a request so the server can recognize duplicates and process the request only once.

Q: What is the difference between at-least-once and exactly-once delivery?
A: At-least-once may duplicate messages. Exactly-once ensures no duplicates, typically with idempotency and deduplication.

Q: What is a watermark in stream processing?
A: A timestamp that indicates when all events up to that time are expected to have arrived, allowing windowed operations to proceed.

Q: What is late data in stream processing?

Q: What is the lambda architecture?
A: A data processing architecture with a batch layer for accuracy and a speed layer for real-time approximations.

Q: What is the kappa architecture?
A: A simplification of lambda that uses only stream processing, treating everything as a stream.

Q: What is change data capture?
A: A pattern for tracking changes in a database and propagating them to other systems in real time.

Q: What is an outbox pattern?
A: A transactional pattern where events are written to an outbox table in the same database transaction as the business data, then published asynchronously.

Q: What is eventual consistency vs strong consistency in distributed systems?
A: Strong consistency guarantees all reads see the latest write. Eventual consistency guarantees reads will eventually see writes if no new updates occur.

Q: What is a consensus protocol?
A: A mechanism for distributed nodes to agree on a single value or state despite failures.

Q: What is the Byzantine Generals Problem?
A: A scenario where nodes must agree on a strategy but some nodes may be faulty or malicious. Solved by Byzantine fault-tolerant algorithms.

Q: What is a quorum in distributed systems?
A: The minimum number of nodes that must participate in an operation to ensure consistency and availability.

Q: What is the difference between synchronous and asynchronous replication?
A: Synchronous: primary waits for acknowledgments from replicas before confirming writes. Asynchronous: primary confirms immediately and replicates in the background.

Q: What is a split-brain scenario?
A: When network partitions cause multiple nodes to believe they are the primary, leading to conflicting writes.

Q: What is fencing in distributed systems?
A: A mechanism to prevent a failed primary from interfering after a new primary has been elected.

Q: What is a hot standby?
A: A replica that is actively receiving updates and can take over immediately if the primary fails.

Q: What is warm standby?
A: A replica that is available but may need a short time to catch up before taking over.

Q: What is cold standby?
A: A backup system that is not running and requires significant time to start and restore data.

Q: What is disaster recovery?
A: The process of restoring systems and data after a catastrophic failure, measured by RTO and RPO.

Q: What is RTO and RPO?

Q: What is chaos engineering?

Q: What is a game day?

Q: What is a blameless postmortem?

Q: What is toil?

Q: What is a runbook automation?

Q: What is USE methodology?
A: Utilization, Saturation, Errors. A monitoring framework for resource-based systems.

Q: What is distributed tracing?

Q: What is tail-based sampling?

Q: What is head-based sampling?

Q: What is structured logging?

Q: What is log aggregation?

Q: What is a metrics time series?

Q: What is exponential backoff?

Q: What is jitter in retry logic?
A: Adding randomness to retry intervals to prevent synchronized retries from multiple clients.

Q: What is a health check endpoint?
A: An endpoint that reports whether a service is running and ready to handle requests.

Q: What is deep health check vs shallow health check?

Q: What is graceful degradation?

Q: What is a fallback in resilience patterns?

Q: What is retry storm?

Q: What is a distributed lock?

Q: What is a saga orchestrator?

Q: What is the difference between orchestration and choreography?

Q: What is an anti-corruption layer?

Q: What is a strangler fig application?

Q: What is a polyglot persistence architecture?

Q: What is a data lake?
A: A centralized repository that stores structured, semi-structured, and unstructured data at scale.

Q: What is a data warehouse?

Q: What is ETL?

Q: When should you choose recursion over iteration for tree problems?
A: Use recursion when the problem divides naturally into identical subproblems on subtrees and code clarity matters more than micro-optimization. Trees are inherently recursive structures.

Q: When should you prefer iteration over recursion for tree problems?
A: Use iteration with an explicit stack or queue when tree depth is unknown or potentially very large. Iteration avoids StackOverflowError on skewed trees and gives you finer control over memory.

Q: What is the main risk of deep recursion in Java or Python?
A: Stack overflow. The call stack has a limited size. A skewed tree with thousands of nodes can crash a recursive solution.

Q: How do you convert a recursive tree traversal into an iterative one?
A: Use an explicit stack. Push the root. While the stack is not empty, pop a node, process it, and push its children. For inorder, push all left children first, then process, then move right.

Q: What is tail recursion and why does it matter?
A: Tail recursion is when the recursive call is the very last operation in the function. In theory it can be optimized into iteration, but Java does not guarantee this optimization, so do not rely on it in interviews.

Q: What is the time and space complexity trade-off between recursion and iteration for tree traversals?
A: Both are O n time. Recursion uses O h implicit stack space. Iteration uses O h explicit stack space. The difference is safety and control, not Big O.

Q: What is the average time complexity of hash map get put and remove?
A: O 1 average case.

Q: What is the worst case time complexity of hash map operations and why?
A: O n when all keys hash to the same bucket, creating a long chain or tree. This happens with a bad hash function or deliberate collision attacks.

Q: What is load factor in a hash map?
A: The ratio of entries to buckets. When it exceeds a threshold, usually 0.75, the hash map resizes to maintain performance.

Q: What happens during a hash map resize?
A: A new larger array is created and all existing entries are rehashed into the new buckets. This single operation is O n but amortized over many inserts.

Q: Why can hash maps not efficiently support range queries?
A: Hash maps scatter keys randomly across buckets. To find all keys in a range, you must scan every bucket, which is O n.

Q: When do you choose TreeMap over HashMap?
A: When you need sorted order, range queries, ceiling, floor, or first and last operations. TreeMap provides O log n guaranteed time.

Q: What is the difference between separate chaining and open addressing for collision resolution?
A: Separate chaining stores colliding entries in a linked list or tree at each bucket. Open addressing probes for the next empty slot in the array.

Q: Why is a good hash function important?
A: It distributes keys uniformly across buckets, minimizing collisions and keeping operations close to O 1.

Q: What is the time complexity of BST search insert and delete?
A: O h where h is height. O log n for balanced trees. O n for skewed trees.

Q: What does inorder traversal of a BST produce?
A: A sorted ascending sequence of values.

Q: How do you validate a BST recursively?
A: Pass valid min and max bounds down the tree. Each node must be strictly greater than min and strictly less than max. Left child inherits the parent's value as new max. Right child inherits it as new min.

Q: How do you validate a BST iteratively?
A: Simulate inorder traversal with a stack. Keep track of the previously visited value. If the current value is ever less than or equal to the previous value, the tree is invalid.

Q: Why is iterative BST validation safer for production code?
A: It uses heap space for an explicit stack instead of the limited call stack, preventing stack overflow on deep or skewed trees.

Q: How do you find the Lowest Common Ancestor in a BST?
A: Compare the two target values with the current node. If both are smaller, go left. If both are larger, go right. Otherwise the current node is the LCA because the values diverge here.

Q: Why is LCA in a BST easier than LCA in a regular binary tree?
A: In a BST you can use value comparisons to decide which subtree to search. In a regular binary tree you must search both subtrees and check where the nodes are found.

Q: How do you find the Kth smallest element in a BST?
A: Perform iterative inorder traversal with a stack. Count nodes as you visit them. Stop and return when the count equals k.

Q: What is the space complexity of Kth smallest using iterative inorder?
A: O h for the explicit stack, where h is the height of the tree.

Q: How do you perform a range query in a BST?
A: Use the BST property to prune branches. If a node value is less than the low bound, only search the right subtree. If greater than the high bound, only search the left subtree. Otherwise process the node and search both children.

Q: What is the time complexity of a BST range query?
A: O log n plus k where k is the number of results in the range. Pruning avoids visiting irrelevant subtrees.

Q: What is the successor of a node in a BST?
A: The node with the smallest value greater than the current node. Go right once, then left as far as possible.

Q: What is the predecessor of a node in a BST?
A: The node with the largest value smaller than the current node. Go left once, then right as far as possible.

Q: What are the three cases for deleting a node in a BST?
A: Leaf node: simply remove it. One child: replace the node with its child. Two children: replace the node with its inorder successor or predecessor, then delete that successor or predecessor from its original position.

Q: What is a self-balancing BST and why does it matter?
A: A BST that automatically keeps height near log n after insertions and deletions. Examples are AVL trees and Red-Black trees. Java TreeMap uses Red-Black tree.

Q: What is the standard binary search template using left less than right?
A: While left is less than right, set mid to left plus right minus left divided by two. If condition is met, set right to mid. Else set left to mid plus one. Return left.

Q: Why use left less than right instead of left less than or equal to right?
A: The left less than right loop invariant guarantees termination and leaves you with left equal to right as the exact answer, avoiding off-by-one errors.

Q: Why calculate mid as left plus right minus left divided by two?
A: To prevent integer overflow. In languages with fixed-size integers, left plus right can overflow before the division.

Q: What is binary search on answer space?
A: When the input array is not sorted but the possible answers form a sorted range. You binary search the range of possible answers instead of the input itself.

Q: What is the sliding window technique used for?
A: Finding optimal contiguous subarrays or substrings that satisfy a specific constraint, like maximum length with all unique characters.

Q: How does the sliding window work?
A: Expand the right pointer to include new elements. When the constraint is violated, shrink the left pointer until the constraint holds again. Track the best valid window seen.

Q: What is the time complexity of sliding window algorithms?
A: O n. Each element is visited at most twice, once by the right pointer and once by the left pointer.

Q: What data structure do you use to track elements inside a sliding window?
A: A HashSet for existence checks, or a HashMap for frequency counts and character positions.

Q: In longest substring without repeating characters, what is the window constraint?
A: All characters inside the window must be unique. When a duplicate is found at the right pointer, move the left pointer past the previous occurrence of that character.

Q: What is the difference between BFS and DFS?
A: BFS uses a queue and explores nodes level by level. DFS uses a stack or recursion and explores as deep as possible along one branch before backtracking.

Q: When should you use BFS on a graph?
A: Use BFS when you need the shortest path in an unweighted graph, or when you need to process nodes level by level.

Q: When should you use DFS on a graph?
A: Use DFS for cycle detection, topological sorting, finding connected components, or when you need to explore a full path before considering alternatives.

Q: How do you detect a cycle in a directed graph using DFS?
A: Track the recursion stack. If you encounter a node that is already in the current recursion stack, a cycle exists. Alternatively use Kahn's algorithm with in-degree counting for BFS.

Q: How do you detect a cycle in an undirected graph using DFS?
A: Track visited nodes and the parent. If you reach a visited node that is not the parent, a cycle exists.

Q: What is the time and space complexity of BFS and DFS on a graph?
A: Time is O V plus E. Space is O V for the visited set and queue or stack.

Q: What is the difference between an adjacency list and an adjacency matrix?
A: Adjacency list stores neighbors for each node, using O V plus E space. Adjacency matrix is a V by V grid using O V squared space. Lists are better for sparse graphs.

Q: What is topological sort and when is it used?
A: An ordering of nodes in a directed acyclic graph such that for every edge from u to v, u comes before v. Used for scheduling tasks with dependencies.

Q: What are two ways to compute topological sort?
A: Kahn's algorithm using BFS and in-degree counting, or DFS with a post-order stack.

Q: What is a bipartite graph and how do you check for it?

Q: What does amortized time complexity mean?
A: The average time per operation over a sequence of operations. For example, ArrayList add is O 1 amortized even though occasional resizing is O n.

Q: What is the difference between worst case and average case time complexity?
A: Worst case is the maximum time for any input of size n. Average case is the expected time over all possible inputs, assuming a probability distribution.

Q: What is the space time trade-off?
A: Using more memory to store precomputed results or indexes in order to reduce computation time, or using less memory at the cost of slower algorithms.

Q: When is O n space considered acceptable in an interview?

Q: What is Big O notation used for?

A: Replacing real dependencies with simulated objects to control behavior and verify interactions in isolation.

Q: What is the difference between a stub and a mock?
A: A stub provides canned answers to calls. A mock verifies that specific methods were called with expected arguments.

Q: What is code coverage and what is its limitation?
A: The percentage of code executed by tests. High coverage does not guarantee correctness if the tests do not assert the right things.

Q: What is the difference between unit tests and integration tests?
A: Unit tests isolate a single component with mocks. Integration tests verify that multiple real components work together.

Q: What is a flaky test?
A: A test that passes or fails inconsistently without code changes, often due to timing, external dependencies, or shared state.

Q: What is the Arrange Act Assert pattern in testing?
A: Arrange: set up the test data and dependencies. Act: execute the behavior being tested. Assert: verify the expected outcome.

Q: What is property-based testing?
A: Testing by defining properties that should always hold, then generating random inputs to find violations.

Q: What is contract testing?
A: Verifying that a service provider satisfies the expectations of its consumers without running the full system together.

Q: What are the three BST traversal orders and what does each visit first?
A: Preorder visits root then left then right. Inorder visits left then root then right. Postorder visits left then right then root.

Q: What does inorder traversal of a BST always produce?
A: A sorted ascending sequence of values.

Q: What is the time complexity of BST search insert and delete in average case?
A: O log n when the tree is balanced.

Q: What is the worst case time complexity of BST operations?
A: O n when the tree is skewed into a linked list.

Q: How do you validate a BST recursively?
A: Pass min and max bounds down the tree. Each node must be strictly greater than min and strictly less than max. Left child inherits current as max. Right child inherits current as min.

Q: Why does the iterative BST validation approach use a stack?
A: It simulates inorder traversal. You keep track of the previous visited node and ensure current is always larger.

Q: Why is iterative validation safer than recursive for deep trees?
A: It uses heap space for an explicit stack instead of the call stack. Recursive validation risks StackOverflowError on skewed trees with thousands of nodes.

Q: What is the Lowest Common Ancestor in a BST?
A: The node where the search paths to two target values diverge. If both values are smaller go left. If both larger go right. Otherwise current node is the LCA.

Q: Why is LCA in a BST easier than LCA in a regular binary tree?
A: In a BST you compare values to decide direction. In a regular binary tree you must search both subtrees because there is no ordering property.

Q: How do you find the Kth smallest element in a BST?
A: Perform inorder traversal and count nodes as you visit them. Stop when count equals k.

Q: What is the space complexity of Kth smallest using iterative inorder?
A: O h where h is the height of the tree for the explicit stack.

Q: What is a range query in a BST?
A: Finding all nodes with values between low and high inclusive. Prune branches if node value is less than low only search right. If greater than high only search left.

Q: What are the three cases for deleting a node in a BST?
A: Leaf node remove directly. One child replace node with that child. Two children replace with inorder successor or predecessor then delete that successor.

Q: What is the inorder successor of a node?
A: The smallest node in the right subtree. Go right once then left as far as possible.

Q: What is the standard binary search template using left less than right?
A: While left is less than right set mid to left plus right minus left divided by 2. If condition met move right to mid else move left to mid plus 1. Return left.

Q: Why calculate mid as left plus right minus left divided by 2 instead of left plus right divided by 2?
A: To prevent integer overflow when left and right are near Integer MAX VALUE.

Q: Why use left less than right instead of left less than or equal to right in binary search?
A: It guarantees termination and avoids infinite loops. The loop ends with left equal to right which is the answer index.

Q: What is binary search on answer space?
A: When the input is not sorted but the possible answer range is sorted. Example finding minimum eating speed or square root.

Q: When does binary search not work?
A: When the search space is not sorted or does not have a monotonic property that lets you discard half.

Q: What is the sliding window technique?
A: Two pointers define a dynamic subarray or substring. Expand the right pointer to include elements. Contract the left pointer when the constraint is violated.

Q: What is the time complexity of sliding window algorithms?
A: O n because each element is visited at most twice once by the right pointer and once by the left.

Q: In longest substring without repeating characters what is the window constraint?
A: All characters inside the window must be unique.

Q: What data structure tracks characters in a sliding window for substring problems?
A: A HashSet for existence checks or a HashMap for character to last seen index.

Q: When should you use sliding window instead of nested loops?
A: When the problem asks for a contiguous subarray or substring that satisfies a condition and brute force would be O n squared.

Q: What is the difference between BFS and DFS?
A: BFS uses a queue and explores level by level. DFS uses a stack or recursion and explores as deep as possible before backtracking.

Q: When does BFS find the shortest path?
A: In an unweighted graph. The first time you reach a node is via the shortest path from the source.

Q: When is DFS preferred over BFS?
A: For cycle detection topological sort exploring all paths or when you need to process a full branch before moving on.

Q: Why does DFS use less memory than BFS on a wide tree?
A: DFS stack depth is O h where h is height. BFS queue can hold an entire level up to O n over 2 for a complete binary tree.

Q: How do you detect a cycle in a directed graph using DFS?
A: Use three colors or states. White is unvisited. Gray is in current recursion stack. Black is fully processed. If you encounter a gray node there is a cycle.

Q: How do you solve Number of Islands?
A: Iterate through the grid. When you find an unvisited land cell increment the count and run DFS or BFS to mark the entire island as visited.

Q: Why can you mutate the input grid in Number of Islands?
A: To mark visited land cells as water. This saves O n times m space that a separate visited matrix would require.

Q: What is the time and space complexity of Number of Islands?
A: Time O n times m to visit every cell once. Space O n times m in worst case for the recursion stack if the entire grid is land.

Q: What are the trade-offs between recursion and iteration?
A: Recursion is cleaner for trees and naturally divided subproblems but risks stack overflow and hides state. Iteration uses explicit stacks or queues safer for deep structures and easier to optimize.

Q: When should you prefer iteration over recursion in an interview?
A: When the tree depth is unknown or potentially very large. When tail recursion optimization is not guaranteed by the language.

Q: What is the time complexity of HashMap get put and remove?
A: O 1 average case. O n worst case if all keys hash to the same bucket causing a long chain.

Q: What is the time complexity of TreeMap get put and remove?
A: O log n guaranteed because it is a Red Black tree.

Q: When do you choose TreeMap over HashMap?
A: When you need sorted order range queries ceiling floor or ordered iteration.

Q: When do you choose HashMap over TreeMap?
A: When you only need fast lookups and do not care about ordering.

Q: What is the difference between a HashSet and a TreeSet?
A: HashSet uses a HashMap for O 1 operations with no ordering. TreeSet uses a TreeMap for O log n operations with sorted ordering.

Q: What causes a HashMap to degrade to O n operations?
A: A poor hash function that causes many collisions. All keys hashing to the same bucket creates a linked list or tree of entries.

Q: How does Java HashMap handle collisions?
A: It chains entries in a linked list. If a bucket exceeds 8 entries and the table is large enough it converts to a Red Black tree for O log n lookup in that bucket.

Q: What is the load factor in a HashMap and what is the default?
A: The ratio of entries to buckets. Default is 0.75. When exceeded the HashMap doubles in size and rehashes.

Q: What is amortized time complexity?
A: The average time per operation over a sequence. ArrayList add is O 1 amortized even though occasional resizing is O n.

Q: What is the difference between time complexity and space complexity?
A: Time complexity measures how runtime grows with input size. Space complexity measures how memory usage grows with input size.

Q: What does Big O notation describe?
A: The upper bound of growth rate. It describes the worst case scaling behavior as input size approaches infinity.

Q: What is the difference between O n and O n squared?
A: O n means linear growth. Doubling input doubles work. O n squared means quadratic growth. Doubling input quadruples work.

Q: Why is O log n considered very efficient?
A: Because the problem size is halved at each step. Even for billions of items log n is around 30.

Q: What is tail recursion?
A: A recursive call that is the last operation in the function. Some languages optimize it to iteration but Java does not guarantee this.

Q: What is memoization?
A: Caching results of expensive function calls to avoid redundant computation. Top down dynamic programming.

Q: What is tabulation?
A: Bottom up dynamic programming. Fills a table iteratively without recursion stack overhead.

Q: What are the two properties required for dynamic programming?
A: Optimal substructure and overlapping subproblems.

Q: What is a greedy algorithm?
A: Makes the locally optimal choice at each step hoping for a global optimum. Does not always yield the optimal solution.

Q: When does a greedy algorithm work?
A: When the problem has the greedy choice property and optimal substructure. Examples include interval scheduling and minimum spanning tree.

Q: What is the two pointer technique?
A: Using two indices often starting at opposite ends or both at the start to traverse a structure in O n time and O 1 space.

Q: What is the fast and slow pointer technique?
A: Two pointers moving at different speeds. Used to detect cycles in linked lists or find the middle element.

Q: What is a deque and when is it useful?
A: A double ended queue supporting add and remove from both ends in O 1. Useful in sliding window maximum problems.

Q: What is a priority queue and what backs it?
A: A queue where elements are ordered by priority. Backed by a binary heap with O log n offer and poll.

Q: What is the difference between a stack and a queue?
A: Stack is LIFO last in first out. Queue is FIFO first in first out.

Q: What is a sentinel node?
A: A dummy node placed at the head or tail of a linked list to simplify edge cases like empty lists or head removal.

Q: What is backtracking?
A: A form of DFS that explores all possible choices and undoes the last choice when a dead end is reached.

Q: What is a complete binary tree?
A: All levels are completely filled except possibly the last level which is filled from left to right.

Q: What is a perfect binary tree?
A: All internal nodes have two children and all leaves are at the same level.

Q: What is the height of a balanced BST with n nodes?
A: O log n.

Q: What is the minimum height of a binary tree with n nodes?
A: Floor of log n. Achieved by a complete or balanced tree.

Q: What is the maximum number of nodes in a binary tree of height h?
A: 2 to the power h plus 1 minus 1.

Q: What is the minimum number of nodes in a binary tree of height h?
A: h plus 1 in a skewed tree.

Q: How many edges are in a tree with n nodes?
A: n minus 1.

Q: What is a self balancing BST?
A: A BST that automatically maintains a small height after insertions and deletions. Examples are AVL trees and Red Black trees.

Q: What is the balance factor in an AVL tree?
A: Height of left subtree minus height of right subtree. Must be minus 1 0 or 1.

Q: What is a Red Black tree?
A: A self balancing BST where each node is red or black. Root is black. No two red nodes are adjacent. Every path from a node to null has the same number of black nodes.

Q: What is a threaded binary tree?
A: A tree where null child pointers are repurposed to point to the inorder predecessor or successor.

Q: What is Morris traversal?
A: An inorder traversal using O 1 space by temporarily creating threaded links to predecessors.

Q: What is the diameter of a binary tree?
A: The longest path between any two nodes. It may or may not pass through the root.

Q: What is path sum in a binary tree?
A: The sum of node values along a path typically from root to leaf.

Q: What is a bipartite graph?
A: A graph whose nodes can be divided into two sets such that no edge connects nodes within the same set.

Q: How do you check if a graph is bipartite?
A: Use BFS or DFS to color nodes with two colors. If you find an edge connecting same colors it is not bipartite.

Q: What is topological sort?
A: An ordering of nodes in a directed acyclic graph such that for every edge u to v node u comes before v.

Q: What algorithm finds topological sort?
A: Kahn's algorithm using BFS and in degree counting or DFS with a post order stack.

Q: What is a Union Find data structure?
A: A disjoint set for tracking connected components. Supports find and union in nearly O 1 with path compression.

Q: What is path compression in Union Find?
A: Flattening the structure during find so that future queries are faster.

Q: What is union by rank in Union Find?
A: Attaching the shorter tree under the taller tree to keep the structure flat.

Q: What is an adjacency matrix?
A: A 2D array where cell i j indicates an edge between node i and node j. Good for dense graphs and O 1 edge lookup.

Q: What is an adjacency list?
A: An array or map where each node points to a list of its neighbors. Good for sparse graphs. Space O V plus E.

Q: When is an adjacency matrix better than an adjacency list?
A: When the graph is dense or you need O 1 edge existence checks.

Q: When is an adjacency list better than an adjacency matrix?
A: When the graph is sparse. Space is O V plus E instead of O V squared.

Q: What is a directed acyclic graph?
A: A directed graph with no cycles. Required for topological sorting.

Q: What is in degree and out degree?
A: In degree is the number of edges entering a node. Out degree is the number of edges leaving a node.

Q: What is a strongly connected component?
A: A maximal subgraph where every node is reachable from every other node.

Q: What is Kosaraju's algorithm?
A: An algorithm to find strongly connected components using two passes of DFS.

Q: What is Dijkstra's algorithm used for?
A: Shortest path from a source to all nodes in a weighted graph with non negative edges.

Q: What is the time complexity of Dijkstra with a priority queue?
A: O E log V.

Q: Why does Dijkstra fail with negative edge weights?
A: Because once a node is popped from the priority queue its shortest distance is assumed final. Negative weights later could invalidate this.

Q: What algorithm handles negative weights?
A: Bellman Ford with time O V times E.

Q: What is the Bellman Ford algorithm used for?
A: Finding shortest paths from a single source in a graph that may contain negative weight edges.

Q: What is the Floyd Warshall algorithm?
A: An all pairs shortest path algorithm with time O V cubed. Uses dynamic programming.

Q: What is the difference between a minimum spanning tree and a shortest path tree?
A: MST connects all nodes with minimum total edge weight. Shortest path tree connects one source to all others with minimum path cost.

Q: What is Kruskal's algorithm?
A: A greedy MST algorithm that sorts edges by weight and adds them if they do not form a cycle. Uses Union Find.

Q: What is Prim's algorithm?
A: A greedy MST algorithm that grows the tree from an arbitrary start node adding the cheapest edge connected to the tree.

Q: What is a spanning tree?
A: A subgraph that includes all vertices and is a tree meaning connected and acyclic.

Q: What is the handshake lemma?
A: The sum of all vertex degrees equals twice the number of edges.
